# 人才發展學習作業系統

此 Repository 為人才發展管理師學習系統的正式主站，後續直接在 `main` 修改與測試，不建立額外測試分支。

## 系統定位

- 工作快複習：30–90 秒卡片、定時提醒、弱點優先。
- 深度學習：依概念單元學習，教材頁碼可追溯。
- 題庫與模考：選擇題、簡答、申論、條項、流程與圖像口述。
- 有聲課程：完整版分章播放、單章／Day／全課循環。
- 學習分析：覆蓋率、回想、完整度、保留度、穩定度。

## 資料分工

GitHub 放網站程式、題庫與學習資料。原始講義圖片、MP3 與大型私人教材保留在 Google Drive，不直接公開到 public repository。

## 維護原則

使用者只看到一套正式網站。版本由 Git commit 管理，不再建立 v8、v9、final-final 類資料夾。
